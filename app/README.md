# Сахарная вата: Все на сцену!

Браузерная пиксельная игра о четырёх участницах группы «Сахарная вата». Марина, Женя, Алиса и Аня должны собрать личные вещи, справиться с шутливыми монстрами прокрастинации и добраться до общего концерта.

## Запуск на компьютере

Двойной клик по `index.html` не запускает проект: ему нужен локальный сервер.

1. Установите актуальную LTS-версию Node.js с https://nodejs.org/.
2. Откройте терминал в папке проекта, где находится `package.json`.
3. Выполните:

```bash
npm install
npm run dev
```

4. Оставьте терминал открытым и откройте http://localhost:3000.

Если npm использует недоступное зеркало, выполните перед установкой:

```bash
npm config set registry https://registry.npmjs.org/
```

### Готовая сборка

```bash
npm run build
npm run preview
```

Адрес будет показан в терминале, обычно http://localhost:4173. Готовые файлы появятся в `dist/`.

## Управление

### Компьютер

- WASD или стрелки — движение;
- E или Enter — разговор, действие, передача вещей, выход;
- Пробел — музыкальная способность;
- Escape или P — пауза;
- M — звук;
- 1–4 — дорожки на концерте.

### Телефон

Игра рассчитана на альбомную ориентацию. Крестовина находится слева, A и B — справа. A отвечает за действия, B — за способность. На концерте появляются четыре кнопки дорожек.

## Игровые системы

- 4 героини, 4 сюжетные главы у каждой — 16 уровней и финальный концерт.
- У каждой героини свои предметы, задания, реплики, монстры и анимация способности.
- Разные поручения: действия кнопкой A, активация объектов способностью, последовательности и возврат найденных вещей NPC.
- Марина разбивает летящие помехи дробью, Женя выпускает направленные ноты, Алиса надолго оглушает вокалом, Аня сильнее отбрасывает басом.
- За находки, задания и победы над помехами начисляются очки и вдохновение. На 100% следующий приём усиливается и восстанавливает сердце.
- На боссах нужно активировать три площадки и ударить босса, пока снята защита.
- Сахарные ноты — необязательные коллекционные предметы. За прохождение выдаются ранги.
- Прогресс хранится только в текущем браузере через localStorage и не синхронизируется между устройствами.

## Проверка

```bash
npm run check
npm run build
```

Для браузерного smoke-теста при установленном Chromium:

```bash
CHROMIUM_PATH=/usr/bin/chromium node scripts/verify-game.mjs
```

Проверены все 16 уровней, новые типы заданий, четыре босса, усиленные способности, концерт, сохранения, клавиатура и сенсорное управление. Тестовая среда — Chromium с программным рендерингом; реальную производительность на конкретном телефоне нужно проверять отдельно.

## Ограничения текущей версии

- Музыка и звуки синтезируются в браузере; оригинальной записи группы пока нет.
- Используются присланные спрайты с процедурными движениями и эффектами, а не отдельно нарисованные покадровые циклы для всех направлений.
- Нет серверных сохранений, аккаунтов и общей сетевой таблицы рекордов.
